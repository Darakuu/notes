## Joint Prospect

[[Prisoner's Dilemma]]-like

Possible Strategies:
- Do nothing (both do nothing)
- Work (only one works)
- Work (both work)

$P_{1}$ Preferences:
(DN, W) $\succ$ (W,W) $\succ$ (DN,DN) $\succ$ (W,DN)
$\quad\quad3\quad \succ \quad2\quad \ \succ \quad\ \ 1\quad \ \ \ \succ \quad0\quad$

$P_{2}$ Preferences:
(W, DN) $\succ$ (W,W) $\succ$ (DN,DN) $\succ$ (DN,W)
$\quad\quad3\quad \succ \quad2\quad \ \succ \quad\ \ 1\quad \ \ \ \succ \quad0\quad$

In Table form:


| $I \text{\\}II$ | W     | DN    |
| --------------- | ----- | ----- |
| W               | $2,2$ | $0,3$ |
| DN              | $3,0$ | $1,1$ |


> [!note] If we change the order of preferences, we obtain a game that is NOT a Prisoner's Dilemma-like
